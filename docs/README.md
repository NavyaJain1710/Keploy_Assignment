# Keploy Gin+Redis Quickstart Guide

This project is a Next.js documentation site demonstrating how to record and replay API tests for a Go Gin+Redis application using Keploy.

## Project Context
This is a DevRel Candidate Assignment submission.

## Tech Stack
- Next.js (App Router)
- MDX for content rendering
- Tailwind CSS (v4) for styling
- TypeScript

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build the production site:
   ```bash
   npm run build
   ```

## Deployment
This static documentation site is optimized for deployment on Vercel. 
Push the repository to GitHub and connect it to Vercel for zero-configuration deployments.
